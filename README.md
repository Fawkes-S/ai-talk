# AI is already here.

A 12-minute classroom presentation with an interactive story map.

- [Presentation](https://fawkes-s.github.io/ai-talk/)
- [Mobile speaker notes](https://fawkes-s.github.io/ai-talk/notes.html)
- [Offline phone notes PDF](https://fawkes-s.github.io/ai-talk/phone-notes.pdf)

## Presenting

Space / Right / Page Down: next. Left / Page Up: previous. M: Map. F: fullscreen. Home: title. End: closing.

No account or ChatGPT login is required. Speaker notes operate independently from the audience display. Download the phone PDF before class for offline access.

All presentation images, scripts and styles are hosted locally within this repository. Sources are available from the presentation menu. The website uses no API keys and makes no AI service calls.
